  The five golden files are in sim/bitstream/fabric_2x2. The driver generates
  fabric_spec.json and logic4_configmem.map in flow/build/fabric-bitstream.
  To reassemble using those files and the standard-library assembler, run
    python3 flow/fasm_to_bitstream.py check sim/bitstream/fabric_2x2 --snapshot-dir flow/build/fabric-bitstream

  Tiles appear in increasing Y, then X. Tile 0 occupies cfg[157:0], with
  consecutive 158-bit slices above it. Multi-tile map rows contain X, Y,
  the global cfg bit and the local frame position (32 * frame + bit).
  In .wiring, each TILE owns its following IN/OUT/LOOP rows. LINK names both
  endpoints of a routed logic-to-logic hop. BEL numbers count four per tile.
  SEL and RED use global cfg bit numbers.

  Experimental coverage on the stand-in switch matrix. Timing, layout, DRC
  and LVS were NOT-RUN. G5/G6 remain open for the ratified fabric.

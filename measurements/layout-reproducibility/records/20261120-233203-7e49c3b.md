# Recovering the logic tile from the routed DEF

The recovered `layout/logic_tile.asbuilt.v` matches the connectivity extracted
from the committed GDS. The DEF and GDS come from the same layout run, as
documented in [layout/README.md](../../../layout/README.md). Recovery used
only the DEF. The SDF and GDS supplied independent checks.

| Check | Result |
| --- | --- |
| Byte regeneration | Generator v1 reproduced `layout/logic_tile.asbuilt.v` exactly. Changing one mux connection in a copy made `--check` fail and preserved the changed file. |
| Cells | All 47 emitted (instance name, cell type) pairs match both the DEF and the named SDF entries after decoding escapes. The empty SDF instance names the `logic_tile` root. The other 165 of 212 DEF components are 149 fillers and 16 well taps. |
| Interface | The seven ports expand to 90 input bits and four output bits. Grouping DEF pin names into descending vectors preserves their numeric indices. Module ports are sorted by name. |
| Supplies | Both supply pins are INOUT. The VGND special net connects VGND and VNB on cells, and VPWR connects VPWR and VPB. The signal-only reference omits both rails and physical-only cells, following the signed LVS reference convention. |
| Signal LVS | `status=match`, zero errors. KLayout anchored all 94 top-level signal pins by name and compared 137 reference nets against 139 extracted nets. |
| Power | `power_connectivity.status=match`, zero findings across 63 extracted instances (47 logic cells and 16 taps). Fillers were excluded from abstraction. KLayout pruned the power-only tap master for signal LVS. |
| Swapped-pin control | Exchanging `lut_init[62]` and `lut_init[63]` on the reference mux gave `status=mismatch` with three errors. Power connectivity still matched. |

The run used Python 3.12.3, Icarus Verilog 13.0, and the tools and PDK in the
metadata above. The GDS extraction reproduced the signed report's layout-side
SPICE hash. The recovered Verilog uses its own formatting and ordering, and
its sanitized bytes differ from the historical reference. KLayout Tools
reported that its tested engine version was 0.30.12 and the installed engine
was 0.30.13.

## Reproduce from the repository root

These Bash commands regenerate into scratch space, check the committed
artifact, and elaborate it with the sky130 HD cell models. Set `PDK_ROOT` to
the installation of the recorded revision (here `$HOME/.volare`).

```bash
set -euo pipefail
scratch=$(mktemp -d)
export PDK_ROOT="$HOME/.volare" PDK=sky130A
klt pdk find --pdk sky130A --expect-version c6d73a35
netlist=layout/logic_tile.asbuilt.v
python3 -I flow/def_to_netlist.py --output "$scratch/recovered.v"
cmp "$scratch/recovered.v" "$netlist"
python3 -I flow/def_to_netlist.py --check
python3 -I flow/test_def_to_netlist.py -v
lib="$PDK_ROOT/$PDK/libs.ref/sky130_fd_sc_hd/verilog"
iverilog -g2012 -gspecify -ginterconnect -T typ -s logic_tile \
  -o "$scratch/tile.vvp" "$netlist" "$lib/primitives.v" "$lib/sky130_fd_sc_hd.v"
```

The following commands run the extract and compare stages from `flow/lvs.sh`.
The pin list comes from the recovered module. Leaving LVS options at their
defaults enables pin anchoring and power checking.

```bash
python3 flow/lvs_sanitize_verilog.py "$netlist" "$scratch/tile.sanitized.v"
pins=$(python3 flow/lvs_declared_pins.py "$netlist")
klt extract layout/logic_tile.gds --deck sky130 \
  --abstract-cells 'sky130_fd_sc_hd__[!f]*' --def-net-names --pins "$pins" \
  -o "$scratch/tile.gate.spice" --format json > "$scratch/extract.json"
jq -e '.status == "extracted"' "$scratch/extract.json"
cat > "$scratch/request.json" <<'JSON'
{
  "schema": "klt.lvs.request/1",
  "engine": "klayout",
  "layout": {"netlist": "tile.gate.spice", "top": "logic_tile"},
  "reference": {"netlist": "tile.sanitized.v", "top": "logic_tile",
                "form": "gate-level-verilog", "library": "sky130_fd_sc_hd"}
}
JSON
klt lvs "$scratch/request.json" --format json > "$scratch/lvs.json"
jq -e '.status == "match" and .power_connectivity.status == "match"' "$scratch/lvs.json"
jq -e 'any(.mismatches[]; .category == "topology.top_level_pins_anchored"
       and .details.pin_count == 94)' "$scratch/lvs.json"
sha256sum "$netlist" "$scratch/tile.sanitized.v" "$scratch/tile.gate.spice"
jq '.environment | {layout_sha256,reference_sha256}' \
  "$scratch/lvs.json" layout/logic_tile.lvs.json
```

The swapped-pin control reuses the extracted SPICE.

```bash
sed -e 's/lut_init\[62\]/swap_bit/g' -e 's/lut_init\[63\]/lut_init[62]/g' \
    -e 's/swap_bit/lut_init[63]/g' "$scratch/tile.sanitized.v" > "$scratch/swapped.v"
jq '.reference.netlist = "swapped.v"' "$scratch/request.json" > "$scratch/swapped-request.json"
klt lvs "$scratch/swapped-request.json" --format json > "$scratch/swapped-lvs.json" || test -s "$scratch/swapped-lvs.json"
jq -e '.status == "mismatch" and .error_count > 0 and .power_connectivity.status == "match"' \
  "$scratch/swapped-lvs.json"
```
